# Мысли

Простой дневник мыслей по психологии для iPhone. Пиксельный стиль, как у темы «Костёр» в Planner.

- Открыть: https://sapronovigor96-jpg.github.io/mysli/
- Поставить на iPhone: открыть ссылку в Safari → «Поделиться» → «На экран „Домой“».
- Записи хранятся только в телефоне. Кнопка со стрелкой вниз сохраняет копию всех записей в файл .txt.
- Работает без интернета (sw.js кэширует файлы). После изменения файлов поднять версию `CACHE` в `sw.js`.
- Котик нарисован скриптом `tools/cat-draw.py`.
